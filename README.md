# workplace-writing

> 职场写作助手 Agent Skill

基于专业职场写作课程方法论（金字塔原理 + SCQA 结构），帮助用户编写或优化各类职场文案：
年终总结、进展汇报、调查报告、请示、邮件、商业计划书、项目计划、工作计划、加薪申请、会议记录、活动方案等。

## 安装

```bash
# 方式一：skills CLI
npx skills add git@github.com:gaorun/workplace-writing.git

# 方式二：直接作为参考资料 cat 进 context
```

## 使用

提出写作需求即可，例如：

- "帮我写一份年终总结"
- "这封邮件怎么回复比较好"
- "写一份加薪申请"
- "帮我把这段报告改得更有说服力"

技能会按以下流程工作：
1. 识别写作类型（总结/调查报告/申请/计划/邮件）
2. 通过交互式提问收集必要信息
3. 用 TCS 三步构思法组织内容
4. 按金字塔结构生成文章
