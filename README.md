# workplace-writing

> 职场写作助手 Agent Skill

基于专业职场写作课程方法论（金字塔原理 + SCQA 结构），帮助用户编写或优化各类职场文案：
年终总结、进展汇报、调查报告、请示、邮件、商业计划书、项目计划、工作计划、加薪申请、会议记录、活动方案等。

## 安装

```bash
# 方式一：skills CLI
npx skills add git@github.com:gaorun/workplace-writing.git

# 方式二：直接作为参考资料 cat 进 context
```

## 使用

提出写作需求即可，例如：

- "帮我写一份年终总结"
- "这封邮件怎么回复比较好"
- "写一份加薪申请"
- "帮我把这段报告改得更有说服力"

技能先分模式，两种模式的流程不同：

- **从零写**：识别写作类型（总结/调查报告/申请/计划/邮件）→ 分轮提问收集信息 → TCS 三步构思 → 按金字塔结构出稿。
  提问有停止规则：单轮最多 3 问、最多 2 轮，信息够就直接出稿；没有数据时用 `【待补：XX】` 占位，不编造数字。
- **改写 / 润色**：不收集信息，只做结构诊断和语言打磨，输出"哪里改 + 为什么改 + 改后片段"，不擅自重写全文。

## 文件结构

| 文件 | 内容 |
|---|---|
| `SKILL.md` | 跨类型的规则与流程：模式判断、类型路由、提问与停止规则、TCS、金字塔与 SCQA、语言质感与温度、输出契约 |
| `types.md` | 每种文案的类型卡片：本质与基调、提问清单、金字塔结构、写作要点、成品示例（年终总结、加薪申请、邮件三篇带完整示例） |

维护约定：同一件事只写一处——跨类型的规则改 `SKILL.md`，只对某一种文案成立的改 `types.md`。
