# 商业计划书

**本质**：写的是这件事值得投，呈现的是完整的商业逻辑。
**基调**：可交付、有证据——每一层判断都要有数据或事实承接。

**提问清单**

- 项目愿景是什么？（一句话高度精炼）
- 市场痛点是什么？
- 你们的解决方案是什么？
- 市场潜力如何？（市场规模、用户画像、竞品分析）
- 你们的独特优势是什么？（行业经验、核心技术、团队）
- 发展规划和盈利模式是什么？
- 需要多少融资或资源？

**数据框架**（`references/project-proposal.md` 共用这一张）

| 要什么 | 口径要求 | 常见锚点 |
|---|---|---|
| 市场规模 | 来源 + 年份 + 口径 | 行业报告、平台数据 |
| 用户画像 | 样本与来源 | 调研记录、后台数据 |
| 竞品对比 | 对比维度 + 时间 | 公开资料、实测 |
| 财务预测 | 假设 + 计算公式 | 内部台账 |
| 融资额度与用途 | 明细 + 时间 | 预算表 |

**内容排序**（按"要话先说"的读者逻辑）

1. **项目愿景**：你要做一件什么样的大事（高度精炼的一句话）
2. **市场痛点**：这件事为什么值得做
3. **解决方案**：这把钥匙能开得了这把锁
4. **市场潜力**：市场规模、用户画像、竞品分析
5. **独特优势**：行业经验、核心技术、牛人团队
6. **发展规划**：盈利模式和发展路径
7. **财务分析**：需要多少钱

**写作要点**

- 首次接触中，退出机制、利润分红等内容不重要，可以不写
- 先讲价值，再讲价格（融资额度放在最后）
- 结构同 `references/project-proposal.md`，两张卡片共用同一套排序
